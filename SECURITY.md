# Security Policy

## Supported versions

Security fixes are applied to the latest release and the `main` branch.

## Reporting a vulnerability

Please report suspected vulnerabilities privately by emailing
[arjunraj@seas.upenn.edu](mailto:arjunraj@seas.upenn.edu). Do not disclose
sensitive details in a public issue.

Include the affected version, impact, reproduction steps, and any suggested
mitigation. We will acknowledge reports as soon as practical, investigate them,
and coordinate remediation and disclosure timing with the reporter.
